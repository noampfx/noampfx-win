NO.AMP FX - KEYGEN
==================
1. Salin file  license_private.pem  (private key Anda, hasil "init") ke folder ini,
   sejajar dengan license_tool.py.   (cukup sekali)
2. Klik dua kali  run_keygen.bat
3. Isi Registered Name + Device ID dari HP user -> Generate -> License Key otomatis
   tersalin ke clipboard. Kirim ke user, lalu user menempel di layar Activate.

Catatan
- Butuh Python 3 + library:  pip install cryptography
- Jangan bagikan license_private.pem. Siapa pun yang memilikinya bisa menerbitkan lisensi.
- Riwayat lisensi tercatat di licenses.csv (di folder ini).
